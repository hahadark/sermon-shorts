# 단축키 설계

원칙
- 기본 편집은 문서처럼 한다. 클릭으로 단어 사이에 커서를 두고 Backspace/Delete로 영상 구간을 지우며, 지운 부분은 클릭 또는 R로 되살린다. D는 Delete의 보조키다.
- 이동은 방향키, 미세 이동은 , . (프레임)와 Shift(10ms), Alt(1ms)로 단계를 통일한다. 자막 화면과 트림 패널에서 같은 규칙을 쓴다.
- 파일·대화상자 작업만 Ctrl 조합을 쓴다.
- 입력칸(제목, URL, 단어 고치기 등)에 글자를 치는 중에는 영상 편집 단축키를 끈다. Ctrl+Z는 입력한 글자만 되돌린다. 단어 고치기는 Enter 확정, Esc 취소, Tab으로 다음 단어를 고친다.
- 모든 단축키는 keymap.js 한 곳의 표에서 정의하고, 도움말(F1 또는 ?)과 버튼 툴팁도 그 표에서 만든다. settings.json의 keymap 항목으로 키를 바꿀 수 있다.

## 기본 화면 (자막 편집)

| 분류 | 키 | 동작 |
|---|---|---|
| 재생 | Space | 편집 결과 재생/정지 (지운 부분 건너뜀) |
| | Shift+Space | 원본 그대로 재생/정지 |
| | K | 정지 |
| | J / L | 2초 뒤로 / 앞으로 (Shift: 5초) |
| | , / . | 1프레임 뒤로 / 앞으로 |
| | Shift+, / Shift+. | 10ms 뒤로 / 앞으로 |
| 이동·선택 | Home / End | 현재 줄 처음 / 끝으로 커서 이동 |
| | Ctrl+Home / Ctrl+End | 전체 처음 / 끝으로 커서 이동 |
| 이동·선택 | ← / → | 단어 사이 커서 이동 (영상도 해당 위치로 이동) |
| | ↑ / ↓ | 위 / 아래 화면 줄의 가까운 위치로 커서 이동 |
| | Shift+방향키 | 선택 넓히기 |
| | Ctrl+A | 전체 선택 |
| | Ctrl+F | 자막 찾기 (Enter 다음, Shift+Enter 이전, Esc 닫기) |
| 편집 | Backspace | 선택 또는 커서 앞 단어 지우기 (이미 지운 단어는 건너뜀) |
| | Delete, D | 선택 또는 커서 뒤 단어 지우기 |
| | Ctrl+Backspace / Ctrl+Delete | 앞 / 뒤 문장 경계까지 지우기 |
| | R | 선택 안의 지운 단어 또는 커서 옆의 지운 덩어리 되살리기 |
| | H | 지운 부분 숨기기 / 보이기 |
| | I | 쇼츠 시작점 = 커서 위치 |
| | O | 쇼츠 끝점 = 커서 위치. I~O 바깥을 모두 지움 |
| | Ctrl+K | 선택만 남기기 |
| | X | 커서 위치에서 끊기(사이 무음 잘라내기) 켜기/끄기 |
| | Enter | 커서 위치에서 자막 줄바꿈 켜기/끄기 |
| | E, F2, 더블클릭 | 단어 글자 고치기 (Enter 확정, Esc 취소, Tab 다음 단어) |
| | Ctrl+Z / Ctrl+Shift+Z, Ctrl+Y | 실행 취소 / 다시 실행 |
| | Ctrl+Shift+C | 자동 정리 (군말, 반복, 긴 쉼) |
| | Ctrl+Shift+T | AI 용어 교정 |
| 컷 | [ / ] | 이전 / 다음 컷으로 이동 |
| | T | 가장 가까운 컷의 트림 패널 열기 |
| 파일 | Ctrl+S / Ctrl+Shift+S | 프로젝트 저장 / 다른 이름으로 저장 |
| | Ctrl+O / Ctrl+Shift+O | 프로젝트 열기 / 영상 파일 열기 |
| | Ctrl+U | 유튜브에서 가져오기 (주소 + 구간) |
| | Ctrl+Shift+U | AI 추천 (주소만) |
| | Ctrl+E | 내보내기 |
| | Ctrl+, | 설정 |
| | F1, ? | 단축키 도움말 |

## 트림 패널 (컷 정밀 조정)

| 키 | 동작 |
|---|---|
| ← / → | 선택한 손잡이 1프레임 이동 |
| Shift+← / → | 10ms 이동 |
| Alt+← / → | 1ms 이동 |
| Tab, 1 / 2 | 손잡이 전환, 1 = A 끝, 2 = B 시작 |
| Space | 이음새 앞뒤 2초 반복 듣기 시작/정지 |
| S / Alt+S | 무음 지점 / 제로 크로싱에 붙이기 |
| R | 자동값으로 되돌리기 |
| [ / ] | 이전 / 다음 컷 |
| Enter | 패널 닫고 이음새 1초 앞부터 재생 |
| Esc | 패널 닫기 |

## 단축키 변경

`settings.json` 파일의 `keymap` 항목에서 단축키를 변경할 수 있습니다. 

```json
{
  "keymap": {
    "play_toggle": ["Space", "P"],
    "delete_fwd": ["d", "D", "Delete"]
  }
}
```

변경 가능한 항목 ID는 `keymap.js`의 `DEFAULT_BINDINGS` 테이블을 참고하세요. 설정 UI에서의 편집은 추후 지원 예정입니다.
