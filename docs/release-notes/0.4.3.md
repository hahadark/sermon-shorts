# 설교 쇼츠 편집기 0.4.3

## 받기
- **Windows**: `SermonShorts-Rust-Setup-0.4.3-x64.exe` ← 보통 이것을 받으세요 (설치판). 압축 해제판은 `SermonShorts-Rust-0.4.3-win-x64.zip`
- **Mac Apple 칩(M1 이상)**: `SermonShorts-Rust-0.4.3-mac-arm64.dmg` · **Mac Intel**: `SermonShorts-Rust-0.4.3-mac-intel.dmg`
- 0.4.0~0.4.2 를 쓰고 있으면 프로그램이 스스로 받아 두었다가 닫을 때 바꿔 끼웁니다.
- Windows: 코드 서명이 없어 처음 실행할 때 경고가 나오면 [추가 정보] → [실행].
- Mac: 처음 받은 dmg 를 열 때 경고가 나오면 시스템 설정 → 개인정보 보호 및 보안 → **그래도 열기**. 키체인을 물으면 **항상 허용**.

## 바뀐 점
- **Mac: 위스퍼 없이 자막 만들기** — macOS 26 이상에서는 맥에 들어 있는 받아쓰기(애플 음성 인식)로 자막을 만듭니다.
  - 따로 설치할 것이 없습니다 (예전에는 시스템 점검에서 위스퍼 엔진 약 3.8GB 를 받아야 했습니다).
  - 매우 빠릅니다: 20분 설교를 약 8초에 받아씁니다. 소리는 맥 안에서만 처리합니다.
  - '음·어' 같은 군말은 거의 받아 적지 않아 [군말 빼기]가 찾는 것이 적을 수 있습니다.
  - 맥 받아쓰기가 안 되면 설치된 위스퍼로 만듭니다. macOS 26 보다 오래된 맥과 Windows 는 예전처럼 위스퍼를 씁니다.
- **Mac 설치 파일이 작아졌습니다**: Apple 칩 dmg 117MB → 약 78MB. 유튜브 도구(yt-dlp)는 처음 유튜브 영상을 불러올 때 공식 최신판을 받아 둡니다.
- 고친 문제
  - Mac: 유튜브 도구를 새 판으로 업데이트한 뒤 "Permission denied" 로 유튜브를 불러오지 못하던 문제

## 확인한 것
- Mac(Apple 칩): 실제 설교로 받아쓰기 — 20분 7.6초, 말소리의 99% 가 낱말 시각 안에 들어오고 낱말 사이 빈틈의 89% 가 실제 무음(컷 편집에 쓸 수 있는 정확도). 앱 코드로 170초 영상 1.4초.
- Mac: yt-dlp 가 없는 처음 상태에서 실행 → 점검 창 없이 시작, 첫 유튜브 불러오기 때 yt-dlp 를 받아 바로 사용
- Mac(Apple 칩·Intel)·Windows: GitHub 서버에서 빌드, 계산 시험, 실행 시험(화면·시험 영상 내보내기). Intel 판에 받아쓰기 도우미가 들어가 동작하는 것 확인
