# v0.3.23 · 시작하자마자 멈추던 문제 수정

v0.3.22를 설치한 일부 Windows PC에서 **실행하자마자 화면이 멈추던 문제**를 고쳤습니다.

## 원인
- Windows 보안의 **제어된 폴더 액세스(랜섬웨어 방지)**가 켜져 있으면, 서명이 없는 SermonShorts가 문서 폴더에 쓰는 것을 막습니다.
- v0.3.22는 시작할 때 배경음악 보관함(`문서\SermonShorts\배경음악`)을 만드는데, 막히면 오류 없이 폴더 만들기를 끝없이 반복해 앱이 응답하지 않았습니다.

## 바뀐 점
- 앱이 폴더를 만드는 모든 곳(17곳)을 안전한 방식으로 바꿨습니다. 막힌 폴더에서도 멈추지 않고 바로 이유를 알려 줍니다.
- 문서 폴더에 쓸 수 없으면 배경음악을 앱 데이터 폴더(`%APPDATA%\SermonShorts\배경음악`)에 대신 보관하고 배경음악 관리 창에서 안내합니다.
- 보관함 폴더 바꾸기, 자료·영상 저장 등에서 막힌 폴더를 고르면 Windows 보안이 막았을 수 있다고 알려 줍니다.

## 문서 폴더를 계속 쓰려면
Windows 보안 → 바이러스 및 위협 방지 → 랜섬웨어 방지 관리 → 제어된 폴더 액세스를 통해 앱 허용 → 허용되는 앱 추가에서 `SermonShorts.exe`를 추가하세요. 추가하지 않아도 앱은 정상 동작합니다.

## 확인한 것
- 제어된 폴더 액세스가 켜진 실제 PC에서 멈춤을 재현하고, 수정 후 0.2초 안에 대체 폴더로 넘어가는 것을 확인했습니다.
- 단위 시험 254개 통과, 실패 0개(운영체제 전용 등 5개 건너뜀). 배경음악·자동 저장·프로젝트 복원·미디어·음성·샘플 실제 앱 시험 통과.

## 내려받기
- **Windows**: `SermonShorts-Setup-0.3.23-x64.exe` (권장), 압축 해제판 `SermonShorts-0.3.23-win-x64.zip`
- **Mac Apple 칩(M1 이상)**: `SermonShorts-0.3.23-mac-arm64.dmg` 또는 ZIP
- **Mac Intel**: `SermonShorts-0.3.23-mac-intel.dmg` 또는 ZIP

v0.3.22에서 멈춰 자동 업데이트를 받지 못하면 위 설치 파일로 덮어 설치하세요. 프로젝트·설정은 그대로 남습니다. 코드 서명이 없는 베타입니다. [설치 안내](https://github.com/hahadark/sermon-shorts/blob/main/docs/INSTALL.md) · 해시는 `SHA256SUMS.txt`
