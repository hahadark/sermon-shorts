# v0.3.22 · 설교 한 편으로 교인 자료와 음성까지

이번 버전은 **교인 자료 스튜디오 확장**과 **원본 영상 자동 복구**를 묶었습니다.

## 교인 자료 만들기
- **만든 뒤 설교와 대조**: 설교에 없는 예화·통계·인용이나 어긋난 문장을 AI가 한 번 더 살펴봅니다. 확인할 문장은 노란 표시와 목록으로 보이고, 누르면 그 문장으로 이동합니다. PDF·이미지에는 표시가 남지 않습니다. 신학을 평가하는 기능은 아닙니다. 기본으로 켜져 있고 AI를 한 번 더 쓰며, 필요하면 끌 수 있습니다.
- **인스타그램 캡션·해시태그**: 카드뉴스·묵상카드에 캡션과 해시태그를 함께 만들고, 고친 뒤 한 번에 복사합니다.
- **자료 3개씩 동시에**: 여러 종류를 고르면 3개씩 나누어 만듭니다.
- **한글·PDF 원고**: HWP·HWPX·PDF를 추가했습니다. 원고 파일 읽기는 기기 안에서 처리합니다. PDF는 20MB·300쪽 이하이며, 스캔 PDF의 글자 인식(OCR)은 지원하지 않습니다. Word·글 파일·자막도 계속 쓸 수 있습니다.

## 듣고 점검하기
- **설교 전달 점검**: 자막 시간으로 1분 구간별 말 빠르기, 2초 이상 공백, 군말·연속 반복 후보를 보여 줍니다. 편집 중인 영상의 후보를 누르면 해당 위치로 이동합니다. AI 호출 없이 기기 안에서 계산합니다.
- **요약·QT 음성으로 듣기**: 컴퓨터의 한국어 음성으로 요약이나 QT를 읽습니다. QT 날짜·음성·속도를 고르고 재생 막대에서 재생·일시정지·위치 이동을 할 수 있습니다. MP3·WAV 저장도 제공합니다. 외부 유료 음성 API를 사용하지 않으며, 한국어 음성이 없으면 설치 방법을 안내합니다.

## 카드 디자인과 샘플
- **카드 디자인 6종**: 새벽 남색·종이·하늘·영상 장면에 잔잔한 초록·잡지를 더했습니다.
- **카드마다 사진 바꾸기**: 내 사진이나 영상 장면을 카드별로 고르고 프로젝트에 보관합니다. 다른 디자인으로 바꿔도 사진은 보관됩니다. 사용 권한이 있는 사진만 골라 주세요.
- **디자인 다시 섞기·전체 PNG 저장**: 글의 순서와 내용은 유지하고 디자인만 바꿉니다. 카드 테두리에 초점을 둔 뒤 좌우 방향키로 이동할 수 있습니다.
- **샘플 설교 체험**: 실제 설교가 아닌 직접 작성한 예시로 9종 자료를 AI 호출 없이 체험합니다. 기존 원고와 자료는 보관되고 돌아갈 수 있습니다. 샘플에서 고친 내용은 원래 자료로 돌아갈 때 사라집니다.

## 원본 영상 자동 복구
- 프로젝트·자동 저장본의 원본 영상이 없으면 유튜브 주소와 받은 구간 정보를 이용해 **같은 부분을 다시 받는 것을 기본 동작**으로 바꿨습니다. 자막·컷·미세 조정·교인 자료를 유지하며 새 파일에 맞게 시각을 옮깁니다.
- 자동 저장본의 **다시 받아 열기**는 추가 확인 없이 받습니다.
- 다운로드가 실패하면 오류를 보여 주고 재시도·파일 직접 찾기·취소로 이어갑니다. 유튜브 주소가 없는 로컬 영상은 파일을 직접 찾습니다.
- 기존에 '먼저 묻기'로 저장한 설정은 유지합니다. 설정 → 일반 → 원본 영상이 없을 때에서 바꿀 수 있습니다.
- 복구 후 저장(Ctrl+S)하면 새 원본 위치가 프로젝트 파일에 기록됩니다.

## 확인한 것과 한계
- Windows 단위 시험 **250개 통과, 실패 0개**. 운영체제 전용 등 5개는 건너뛰었습니다.
- 실제 앱에서 교인 자료·사진·음성·샘플·한글 PDF·프로젝트 복원과 MP4 출력을 검증했습니다.
- 전달 점검은 자동 자막 기준 참고 자료입니다. 자막 공백이 실제 무음은 아닐 수 있고, 반복과 쉼은 강조·기도·회중 응답일 수 있습니다. 신학·대지·적용 비율은 평가하지 않습니다.
- AI 대조도 오류를 놓칠 수 있으므로 공개 전 직접 확인해 주세요.
- 음성 듣기는 Windows에서 실제 재생·MP3/WAV 저장을 검증했습니다. Mac 한국어 음성 합성은 구현했으나 실기 검증 전입니다.

## 내려받기
- **Windows**: `SermonShorts-Setup-0.3.22-x64.exe` (권장), 압축 해제판 `SermonShorts-0.3.22-win-x64.zip`
- **Mac Apple 칩(M1 이상)**: `SermonShorts-0.3.22-mac-arm64.dmg` 또는 ZIP
- **Mac Intel**: `SermonShorts-0.3.22-mac-intel.dmg` 또는 ZIP

Windows 설치판과 Mac v0.3.19 이상(응용 프로그램 폴더의 앱)은 자동 업데이트됩니다. 코드 서명이 없는 베타이며 Mac은 Apple 공증을 받지 않았습니다. [설치 안내](https://github.com/hahadark/sermon-shorts/blob/main/docs/INSTALL.md)를 확인하세요. 파일 확인용 해시는 `SHA256SUMS.txt`에 있습니다.
