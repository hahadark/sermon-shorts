# v0.3.26 · 클로드 로그인 창에서 붙여넣기

## 클로드 연결
- **AI 연결 → 클로드 → [클로드 로그인]**을 누르면 이제 **Windows 터미널** 창이 열립니다. 예전 검은 명령 창에서는 클로드가 코드를 붙여 넣으라고 할 때 붙여넣기가 되지 않는 경우가 있었습니다. 새 창에서는 **Ctrl+V** 또는 **마우스 오른쪽 클릭**으로 붙여 넣으면 됩니다.
- **[Claude Code 설치]** 창도 같은 터미널로 엽니다. 다른 터미널 창에 탭으로 끼어들지 않고 늘 새 창으로 열립니다.
- Windows 터미널이 없는 PC에서는 예전처럼 명령 창으로 엽니다.

## 확인한 것
- 단위 시험 272개 통과, 실패 0개(운영체제 전용 등 5개 건너뜀).
- 새 창 열기: Windows 터미널로 열리는지, 한글·따옴표·세미콜론이 섞인 명령이 깨지지 않고 그대로 실행되는지 실제로 확인했습니다.
- 실제 클로드 계정 로그인은 사용자 계정이라 자동 시험으로 하지 않았습니다.

## 내려받기
- **Windows**: `SermonShorts-Setup-0.3.26-x64.exe` (권장), 압축 해제판 `SermonShorts-0.3.26-win-x64.zip`
- **Mac Apple 칩(M1 이상)**: `SermonShorts-0.3.26-mac-arm64.dmg` 또는 ZIP
- **Mac Intel**: `SermonShorts-0.3.26-mac-intel.dmg` 또는 ZIP

Windows 설치판과 Mac v0.3.19 이상(응용 프로그램 폴더의 앱)은 자동 업데이트됩니다(도움말 → 업데이트 확인). 코드 서명이 없는 베타입니다. [설치 안내](https://github.com/hahadark/sermon-shorts/blob/main/docs/INSTALL.md) · 해시는 `SHA256SUMS.txt`
