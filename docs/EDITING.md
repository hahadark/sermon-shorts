# 자막 편집 방식 (Vrew식 커서 편집)

목표: 자막을 문서처럼 다룬다. 커서를 단어 사이에 두고 Backspace/Delete로 지우면 그 영상 구간이 잘린다. 지운 것은 쉽게 되살린다.

## 현재 화면: 14자 자막 블록과 두 텍스트 트랙
- 긴 문단 대신 실제 출력 자막 한 줄마다 번호·시각·글자 수를 가진 블록으로 표시한다. 기본 최대 14자(공백 제외)이며 기존 길이 설정을 따른다.
- **STT 원문**: 처음 인식한 텍스트를 보존한다. 단어 선택과 Backspace/Delete로 영상 구간을 삭제하고, 취소선의 되살리기로 복원한다.
- **출력 자막**: 아래 입력칸에서 문장 전체를 수정한다. 미리보기에 즉시 반영되며 Enter 또는 다른 곳 클릭으로 적용, Esc로 이번 수정을 취소한다. Tab은 다음 출력 칸으로 이동한다.
- 출력 자막을 고쳐도 원문·단어 시각·영상 컷은 바뀌지 않는다. 긴 문장은 적용 시 최대 글자 수에 맞춰 다시 나뉜다. 빈칸은 자막만 숨기며 영상은 유지한다.
- 수정 내용은 인식 단어에 연결해 보관하므로 글자 수 변경·컷 편집 후에도 유지된다. 원문과 수정 자막 모두 프로젝트에 저장하고 실제 출력 자막만 MP4·SRT로 내보낸다.
- 예전 프로젝트는 저장된 원문 필드 또는 기존 오타 교정 원문이 있으면 복구한다. 원문 기록이 전혀 없는 과거 파일은 현재 텍스트를 최초 원문으로 삼는다.

## 처음 쓰는 방법
1. 지우려는 단어의 오른쪽을 클릭한다. 단어 뒤에 세로 커서가 생긴다.
2. **Backspace**를 누르면 앞 단어와 해당 영상 구간이 지워진다. 여러 단어는 마우스로 끌어 선택한 뒤 Backspace를 누른다.
3. 잘못 지웠다면 **Ctrl+Z**. 나중에 되살리려면 흐린 취소선 단어를 클릭하고 **되살리기**를 누른다.
4. **지운 부분 숨기기**를 누르면 남은 문장만 볼 수 있다. 숨긴 구간 표시를 클릭하면 다시 펼쳐진다.
5. 오타나 문장 수정은 아래 **출력 자막** 칸에서 한다. 단어 더블클릭/F2는 출력 단어만 고치는 보조 기능이다.

아래는 구현·검증에 사용하는 상세 규칙이다.

## 커서 모델
- 커서는 "단어 사이 경계"에 있다: 위치 i = i번째 단어 앞 (0 ~ 단어 수). 화면에는 깜빡이는 세로선.
- 클릭: 클릭한 단어의 왼쪽 절반이면 그 단어 앞, 오른쪽 절반이면 그 단어 뒤에 커서. 영상은 커서 오른쪽 단어의 시작으로 이동(편집 결과 재생 모드면 지운 단어는 건너뛴 위치).
- 재생 중에는 커서가 현재 말하는 단어 앞을 따라간다(사용자가 클릭/키 조작하면 따라가기 멈춤, 재생 다시 시작하면 다시 따라감).
- ←/→: 커서를 한 단어씩 이동 (지운 단어 위도 지나간다: 지운 단어도 커서 이동 대상). ↑/↓: 윗줄/아랫줄의 가장 가까운 x 위치. Home/End: 줄 처음/끝. Ctrl+Home/End: 전체 처음/끝.
- 선택: 마우스 끌기, Shift+클릭, Shift+방향키. 선택은 [a, b) 단어 범위로 강조.

## 지우기 / 되살리기
- Backspace: 선택이 있으면 선택 범위 지우기. 없으면 커서 앞쪽으로 가장 가까운 "살아 있는" 단어 하나를 지우고 커서를 그 단어 앞으로 옮긴다(이미 지운 단어는 건너뜀).
- Delete: 같은 방식으로 커서 뒤쪽 살아 있는 단어 하나.
- Ctrl+Backspace / Ctrl+Delete: 커서 앞/뒤 문장 끝(. ? ! 또는 줄바꿈)까지 지우기.
- 지운 단어 표시: 흐린 회색 + 취소선, 연속된 지운 단어는 한 덩어리(run)로 묶어 옅은 빨간 배경.
- 되살리기:
  1. 지운 덩어리를 클릭하면 덩어리 위에 작은 [되살리기] 버튼. 누르면 그 덩어리 전체 복원.
  2. R: 선택 범위 안의 지운 단어 복원, 선택이 없으면 커서에 닿아 있는 지운 덩어리(앞 또는 뒤) 복원.
  3. Ctrl+Z / Ctrl+Shift+Z: 실행 취소 / 다시 실행 (모든 편집 공통).
- [지운 부분 숨기기] 토글(단축키 H): 켜면 지운 단어를 감추고 그 자리에 작은 가위 표시만 남긴다. 가위 표시를 클릭하면 숨긴 내용이 펼쳐진다.

## 그 밖의 편집
- 더블클릭 또는 F2/E: 단어 글자 고치기(오타). Enter 확정, Esc 취소, Tab 다음 단어로 이어서 고치기.
- Enter: 커서 위치에서 자막 줄바꿈 켜기/끄기 (앞 단어의 br).
- X: 커서 위치(커서 뒤 단어 앞)의 쉼 잘라내기 켜기/끄기 (cutBefore).
- I / O: 커서 위치를 쇼츠 시작/끝으로.
- Ctrl+K: 선택만 남기기.
- 가위(컷) 표시 클릭 또는 T: 트림 패널.
- 글자 키(I, O, X, R, H, T, D, J, K, L)는 단어 고치기 입력 중에는 글자로 입력된다.

## 화면
- 자막 영역은 한 문서처럼 이어진 문단(문장 끝 또는 1.5초 이상 쉼에서 문단 나눔), 문단 앞에 원본 시각.
- 상단 도구줄: [지운 부분 숨기기] [되살리기(R)] [선택만 남기기] [자동 정리] 그리고 결과 길이·컷 수.
- 첫 사용 안내 한 줄: "클릭해서 커서를 두고 Backspace로 지우기 · 지운 부분 클릭 → 되살리기 · Ctrl+Z 실행 취소".

## 자막 한 줄 최대 글자 수
- 자막 창 위쪽 **자막 한 줄 최대**에 1~200자를 입력한다. 기본 14자이며 8·12·14·16·20자 프리셋을 제공한다.
- 공백은 세지 않고 문장부호는 센다. 문장 끝·긴 쉼·수동 줄바꿈은 그대로 존중하며 단어 경계를 우선한다.
- **긴 단어도 나누기**를 켜면 한 단어가 제한을 넘을 때 표시 자막만 나눈다. 끄면 긴 단어 하나는 제한을 넘을 수 있다.
- 긴 단어를 나눌 때 표시 시각은 해당 단어의 시간 안에서 글자 수에 비례해 배분한다. 음절별 재인식이 아니며 원본 단어·영상 컷은 바뀌지 않는다.
- 변경은 미리보기·MP4·SRT에 함께 적용되고 프로젝트 저장/복원 및 Ctrl+Z/다시 실행에 반영된다. 이전 프로젝트는 기존의 긴 단어 유지 동작을 보존한다.

## 행 합치기와 체크박스 일괄 삭제
- 출력 자막의 맨 앞에 커서를 두고 Backspace를 누르면 위 출력 자막과 합친다. 첫 행에서는 아무 것도 지우지 않는다. 한글 조합 중이거나 선택 범위가 있거나 행 중간인 경우에는 일반 글자 삭제를 한다.
- 합친 위치에 커서를 유지한다. STT 원문·영상 시각·영상 컷은 바꾸지 않으며, Ctrl+Z/다시 실행으로 병합을 취소·복구할 수 있다.
- 수동 병합은 자동 14자 제한보다 우선한다. 초과해도 다시 갈라지지 않으며 **14자로 다시 나누기** 버튼으로 자동 분할로 돌아간다. 병합 결과는 프로젝트·MP4·SRT에 유지된다.
- 각 블록 앞 체크박스로 여러 구간을 고르고 **선택 구간 삭제**를 누르면 선택한 영상 구간을 한 번에 삭제한다. 체크하지 않은 구간과 인식 원문은 보존한다.
- **전체 선택**과 **선택 해제**를 제공한다. 체크만 해서는 영상을 바꾸지 않으며, 일괄 삭제는 Ctrl+Z 한 번으로 전체 복원한다.
- 영상 삭제의 기본 단위는 인식 단어다. 긴 단어를 여러 자막으로 나눠 표시한 경우 그 단어를 공유하는 블록은 함께 선택된다. 단어 안의 정밀한 컷은 트림 패널을 사용한다.
